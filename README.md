# FGEditor

> FlexGravity 配套的重力场 / 作用域编辑器。

**功能简介：**
- 支持编辑匀强场、单极子场、线场、面场参数。
- 支持使用函数自定义场和作用域。
- 支持任意场源和作用域配对。

## 0. 使用前准备

参照 FlexGravity 配套的自定义重力场制图教程（见 https://github.com/qwertye303/FlexGravity ）制作地图，确保已经创建好下面这些 FG 组，并把对应的物体归入对应的组，导出 nmo 文件：

```text
FG_UField
FG_MField
FG_LField
FG_SField
FG_Region
```

注：`FG_CField` / `FG_CRegion` 组由编辑器在导出时创建，第一次导入时可以没有这两个数组。

## 1. 使用FGEditor制作你想要的重力场

1. 打开 `FGEditor.exe`，点`导入 NMO`，选择你刚刚保存的nmo文件。
2. 在`场、作用域设置`下的 `U / M / L / S / CF / R / CR` 页里编辑场和作用域，在`场-作用域配对`下的 `Local / Global` 页里配对。

### 具体参数说明:

### 场、作用域设置

#### 1. U（匀强场）
- 在x、y、z方向上产生对应参数的重力加速度 **（20为游戏原版重力，下同）**

#### 2. M（单极子场）
- 以单极子对象的坐标轴心为原点，产生径向的 $\dfrac{G}{r^2}\$ 的重力加速度， $G > 0$ 为指向单极子源。

#### 3. L（线场）
- 在线上分布密度为 $Lambda$ 的重力源，若无限长则沿径向产生 $\dfrac{Lambda}{r}\$ 的重力加速度， $Lambda > 0$ 为指向线源。**有限长要考虑边界效应。**

#### 4. S（面场）
- 在面上分布密度为 $Sigma$ 的重力源，若无限大则沿法向产生 $Sigma$ 的重力加速度 **（匀强场）**， $Sigma > 0$ 为指向面源。**有限大要考虑边界效应。**

#### 5. R（作用域）
- 只读列表，显示 `FG_Region` 组里已有的作用区域。

#### \*6. CF（自定义场）
- 使用函数自定义你想要的场。
- 直角坐标使用 `x, y, z`，需要填 `X / Y / Z`；球坐标使用 `r, theta, phi`，需要填 `R / Theta / Phi`。
- **门槛可能有点高，有想法但不会实现的可以问AI，让它帮你生成函数表达式，复制进去检查一下函数语法就行！**  
*例：在 -1 < y < 1 生成沿 xz 平面的离心场，系数是 1，则直角坐标参数：X = x, Y = 0, Z = z；或者使用球坐标参数： R = r\*cos(phi)^2, Theta = 0, Phi = -r\*sin(phi)\*cos(phi)。作用域在 CR 页填写：-1 < y < 1。之后去把它们两个配对*
- 首次使用前请先点击`场函数填写说明`并阅读相关事项。
- 编辑完请点击`检查`来确认是否有语法错误，**有语法错误导出地图后游戏可能不认！**

#### \*7. CR（自定义作用域）
- 使用函数自定义你想要的作用域。
*例：在 -1 < y < 1 生成沿 xz 平面的离心场，则可以在 CR 页填写：-1 < y < 1。*
- 首次使用前请点击`作用域填写说明`。
- 编辑完请点击`检查`来确认是否有语法错误，**有语法错误导出地图后游戏可能不认！**

### 场-作用域配对

#### 1. Local（局部作用）
- 第一列是每个 `FG_Region` 成员和每个 `CR` 对象，增删改 `CR` 第一列对象会实时刷新。
- 双击第二列选择在该作用域内起作用的场源，源可以是 M / L / S / CF，**U 自带区域，因此不出现在选择列表中，也不需要配对！**

#### 2. Global（全局作用）
- 放在这里的源会对整张自制图生效。

**注：若局部和全局都不放，就是不起作用。**

3. 点`导出 NMO`，即可开始游玩！

## 2.如果需要修改参数

直接导入已经导出的nmo即可，会把数据重新读进来，编辑完再导出就行！

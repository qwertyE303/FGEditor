# FGEditor

> FlexGravity 配套的重力场参数编辑器。

**功能简介：**
- 支持编辑匀强场、单极子场、线场、面场参数，以及设置每个场的作用区域。
- 支持使用函数自定义场。

## 0. 使用前准备

参照FlexGravity配套的自定义重力场制图教程（见 https://github.com/qwertye303/FlexGravity ）制作地图，确保已经创建好FG组并将对应的物体归入对应的组，并导出nmo文件。

## 1. 使用FGEditor制作你想要的重力场

1. 打开 `FGEditor.exe`，点`导入 NMO`，选择你刚刚保存的nmo文件。
2. 在 `U / M / L / S / R / RG` 页里编辑参数。

### 具体参数说明:

### 1.U：匀强场
- 在x、y、z方向上产生对应参数的重力加速度 **（20为游戏原版重力，下同）**

### 2.M：单极子场
- 以单极子对象的坐标轴心为原点，产生径向的 $\dfrac{G}{r^2}\$ 的重力加速度， $G > 0$ 为指向单极子源。

### 3.L：线场
- 在线上分布密度为 $Lambda$ 的*重力强度（注：这个是我自己想的名字）*，若无限长则沿径向产生 $\dfrac{Lambda}{r}\$ 的重力加速度， $Lambda > 0$ 为指向线源。**有限长要考虑边界效应。**

### 3.S：线场
- 在面上分布密度为 $Sigma$ 的*重力强度*，若无限长则沿法向产生 $Sigma$ 的重力加速度 **（匀强场）**， $Sigma > 0$ 为指向面源。**有限长要考虑边界效应。**

### 4.R：作用区域
- 第一列是你的作用区域，后面的是你想要在这个作用区域起作用的源。

### 5.RG：全局作用
- 把你想要整张自制图都起作用的源放在这里！**（R和RG都不放就是不起作用）**

### 6.Custom：自定义重力场（进阶操作）
- 使用函数自定义你想要的场。
- **门槛可能有点高，有想法但不会实现的可以问AI，让它帮你生成函数表达式和作用区域，复制进去检查一下函数语法就行！**  
*例：在 -1 < y < 1 生成沿 xz 平面的离心场，系数是 1，则直角坐标参数：X = x, Y = 0, Z = z；或者使用球坐标参数： R = r\*cos(phi)^2, Theta = 0, Phi = -r\*sin(phi)\*cos(phi)。作用区域：-1 < y < 1。*
- 首次使用前请先点击`函数填写说明`并阅读相关事项，具体我就不在这里写了。
- 编辑完请点击`检查`来确认是否有语法错误，**有语法错误导出地图后游戏可能不认！**

3. 点`导出 NMO`，即可开始游玩！

## 2.如果需要修改参数

直接导入已经导出的nmo即可，会把数据重新读进来，编辑完再导出就行！
